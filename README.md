# Amazon Review Sentiment & Emotion Analysis

A two-step pipeline that predicts sentiment from Amazon review **title + text
only** (the star rating is never used as a feature), then evaluates those
predictions against rating-derived ground truth in a locally hosted
Streamlit dashboard. Also scores each review against the NRC basic emotions
(anger, anticipation, disgust, fear, joy, sadness, surprise, trust).

## Pipeline

**Step 1 — `step1_sentiment_model.py`** (spec: `Goal.md`)
Lexicon-based classifier, no ML training and no rating access:
1. Combine each review's `title` + `text`.
2. Split into sentences and drop any sentence with `MIN_SENTENCE_WORDS`
   (currently 8) or fewer words — short sentences like "Works great!" are
   ignored so scoring leans on substantive text.
3. Count NRC-lexicon word matches (see below) in the surviving sentences.
4. `predicted_sentiment` = whichever of positive/negative has more matches;
   a tie (including 0-0) is `ambiguous` and logged to `ambiguity.md`.
5. `dominant_emotion` = whichever of the 8 basic emotions has the most
   matches, by the same tie-to-`ambiguous` rule.

Outputs `predictions.csv` (per-review counts + predictions) and
`ambiguity.md` (design notes plus a table of every tied review).

**Step 2 — `step2_dashboard.py`** (spec: `Analysis.md`)
Streamlit dashboard that:
- Loads ground truth from the raw dataset: rating ≤ 2 → negative, rating = 3
  → ambiguous, rating ≥ 4 → positive.
- Scores Step 1's predictions against that ground truth: confusion matrix,
  accuracy, precision/recall/sensitivity/specificity, per-product metrics.
- Surfaces `ambiguity.md` (tie counts, recurring words) and the emotion
  breakdown (dominant-emotion distribution, emotion mix by star rating).
- Includes a **"Classify a review"** form to run arbitrary title/text
  input through the same Step 1 model interactively.
- Filterable by product (ASIN), star rating, predicted sentiment, and
  dominant emotion.

## Lexicon

`lexicon.py` loads word lists from `NRCLexicon/*.txt` — the NRC
Word-Emotion Association Lexicon, one file per category (`positive`,
`negative`, and the 8 basic emotions), each a `word<TAB>0|1` association
list over the same ~14k-word vocabulary.

## Data

- `amazonreviewdata.jsonl.gz` — raw review records (one JSON object per
  line). Schema described in `metadata`.
- `predictions.csv` / `ambiguity.md` — generated by Step 1; gitignored, not
  committed. Regenerate by running Step 1 (see below).

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirments.txt
```

## Running

```bash
# Step 1: score reviews, write predictions.csv + ambiguity.md
.venv/bin/python step1_sentiment_model.py

# Step 2: launch the dashboard
.venv/bin/streamlit run step2_dashboard.py
```

The dashboard is served locally at http://localhost:8501.
